# تثبيت دفتر القروض على الآيفون

## 1) النشر على GitHub Pages (مرة واحدة)
1. في github.com اضغط + ثم New repository، الاسم: daftar، واختر **Public** (ضروري للنشر المجاني)، ثم Create repository.
2. اضغط uploading an existing file، واسحب **كل ملفات** هذا المجلد (index.html و sw.js و manifest.webmanifest والصور الأربع) إلى الصفحة، ثم Commit changes.
3. اذهب إلى Settings ثم Pages. تحت Build and deployment اختر Source: Deploy from a branch، والفرع main والمجلد / (root)، ثم Save.
4. انتظر دقيقة إلى 3 دقائق، وسيظهر في أعلى صفحة Pages رابط التطبيق، مثل: https://اسم-حسابك.github.io/daftar/

## 2) التثبيت على الآيفون
1. افتح الرابط في **Safari** (وليس كروم).
2. اضغط زر المشاركة (المربع والسهم للأعلى) ثم **إضافة إلى الشاشة الرئيسية** ثم إضافة.
3. افتح التطبيق من أيقونته على الشاشة الرئيسية. بعد أول فتح يعمل بدون إنترنت.

## ملاحظات
- بياناتك تُحفظ على الآيفون داخل التطبيق فقط، والمستودع لا يحتوي بياناتك.
- لتحديث التطبيق لاحقاً: ارفع index.html الجديد إلى المستودع بنفس الطريقة، وبعد دقيقة يتحدّث التطبيق عند فتحه وأنت متصل بالإنترنت.
- احفظ نسخة احتياطية من الإعدادات بين وقت وآخر.
